## How the Teaching Works

This entire curriculum is AI-assisted — I'm being taught and graded by **Google Gemini (Antigravity)** acting as a personal DevOps instructor, following a custom rule set I built with it.

### The Q&A System

Every day after studying a topic, I get **10 questions** generated by the AI. These aren't trivia — they're designed to break you if you only memorized the docs:

- No "what is X?" or "list the flags for Y" — those test memory, not understanding
- Instead: *"What breaks if you do X?"*, *"Why does Linux do it this way?"*, *"What's the danger of..."*
- Questions escalate — Q1–Q3 are foundational, Q4–Q7 are applied, Q8–Q10 are designed to be hard
- At least one script-writing question and one "find the bug" question per day
- Questions only cover topics up to and including the current day — no testing on things I haven't learned yet

I write my answers in `notes/dayX.txt`, then the AI reads the file and grades it.

### The Grading System

- Grading is generous — if I show I understand the concept, I get the point even if my wording isn't textbook
- Wrong *reasoning* costs marks, not wrong syntax — mental model matters more than memorizing commands
- Every deduction comes with a clear correction so I actually learn from mistakes
- Bonus recognition (not extra marks) for insights beyond what was asked
- Score format: X / 10

### Mini-Project Days

On project days (Day 7, 14, 20–21), there are no questions — I get project requirements and build from scratch. The AI reviews for correctness, robustness, style, and whether I actually used that week's concepts.

### Why This Works

The AI doesn't let me get away with surface-level answers. It forces me to reason about systems the way you'd need to in production — *"what happens when this fails at 3 AM and nobody's awake?"* That's the kind of thinking this setup trains.
