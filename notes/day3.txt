6. What is the difference between kill, kill -9, and kill -15? When would you use each?

kill and kill -15 do exactly same thing. It send a termination siganl to the procecess. signal 15 is a gracefull termination request. when a process receives this signal it close the open files and network connections, save user data or current progress, cleanup temporary files and terminates it's child processes properly. kill -9 is force termination.This handled by kernal itself. kernal forcefully removes process from memory immediately. we use kill and kill -15 for default and safe process terminations whlie kill -9 is used when a process is frozen or unresponsive.

7. What is a zombie process? What causes it and why is it a problem?

a zombie process is a child process that already finished its job and parent process still hasnt read its exit code or parent failed or refused to kill that child process. A single zombie process isnt problem. But if multiple programs has parent processes that failed or refuses to kill the child processes there could be thousands of zombie processes.Linux has a finite number of PIDs. If the system has too many zombie process it can exhaust the available PIDs and block the system from launching new programs, services or connections.
You cant kill a zombie process because its already dead. Even with the force kill. You have to kill its parent process.
