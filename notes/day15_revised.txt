Q4. Your colleague suggests replacing -exec chmod +x {} \; with -exec chmod +x {} +. What changes under the hood, and when would it matter?

{} \; will fork the shell for every argument that passed to it then increse the x bit and exit.It will create and terminate processes as long as there are arguments.{} + will increase the x bit of all the argument passed to it all at once making only one child process.It matters when working will massive set of data that needs passed to the command.if you are to modify x bit of small number of {} \; will work fine but if you need to change 10000 files it will create 10000 sub processes under the hood and propably hit argument list limit(ARG_MAX).But {} + work smartly if all the files couldnt fit in to one array by hitting ARG_MAX it will break them into managebale multiple arrays and run the command.This will still create multiple child processes but its less than {} \;.
