variable scope is the region or context in a computer program where a specific variable is visible,accessible and can be used.Once execution leaves that region the variable can no longer be accessed and memory is released.
No you can only access it inside that specific function.You have to make it a global variable. It means you have to declare the varible outside that funcion or any other functions.If you wanna make it truely local you need to declare that varible inside the specific function,method or code block that you wanna use.

variable scope types

*Local variable - variables declared inside a specific function,method or code block.they can only be used inside exact function or block and are destroyed after execution.
*Global variable - variables declaered outside of any function or block(usually at the top of the file). They are accessible from anywhere in that program
*Block scope - variables declared inside curly brackets or control structures(like loops or if statements) using keywords like let or const. Their use is limited to that code block.
Function scope - In languages like javascript or python variables declared inside a function body are bound to the entire function regardless of inner block boundaries.
