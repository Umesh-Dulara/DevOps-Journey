Q1. What is the difference between a for loop and a while loop in bash? When would you choose one over the other — give a real scenario for each.

The difference is how they determine their execution length.A for loop iterates over a predefined list of items or elements but while loop contineus its execution as long as a specified condition evaluates to true.
we use for loops when we know the exact items, files or range beforehand. (eg: to print the first 5 lines of a file)
we use while loops when the number of iterations depends on dynamic criteria. (eg: when reading an unpredictable stream of data. to read all the number of lines where we dont know the exact number of lines contain in the file.)

Q5. What is an until loop? How is it different from while? Rewrite this while loop as an until loop:

An until loop repeat the code block inside the loop as long as specified condition is false and stops the moment that condition becomes true.

bash


NUM=10
while [ $NUM -gt 0 ]; do
    echo "$NUM"
    NUM=$((NUM - 1))
done

NUM=10
until [ $NUM -eq 0  ]
do
	echo "$NUM"
	NUM=$((NUM - 1))
done

    COUNT=$((COUNT + 1))

The difference is when you use a pipeline bash forks a seperate backgrount anvironment(subshell) to run the loop. any variable you create inside that loop vanish completely after loop finishes. process substitution and here-strings keep the loop in the main shell allowing variables to survive.

in this code echo command is piped to while loop.Increment happens inside the loop and words will assign to the word variable and loop will run. But the COUNT variable is called outside of that loop which means it runs in main shell. so even thogh the variable was incremented inside the subshell it naver made it into the main shell.
